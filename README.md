# IT Support Capstone Project: Ubuntu Innovations (Pty) Ltd

## Project Summary

This repository contains a four-week IT Support Capstone Project completed for the CAPACITI Tech Career Accelerator and Google IT Support Professional Certificate learning pathway.

The project presents a complete IT infrastructure and support proposal for **Ubuntu Innovations (Pty) Ltd**, a Cape Town-based technology startup with 25 employees. The scenario requires the design of a secure, scalable and professionally documented IT environment to support the company’s relocation into a new office and its continued business growth.

The final solution covers business requirements, hardware and software recommendations, network design, IP addressing, user permissions, operating system administration, backup and disaster recovery, cybersecurity, risk management, incident response, troubleshooting and career-readiness documentation.

## Solution Overview

The proposed IT solution is designed to support Ubuntu Innovations as a growing organisation. It provides reliable connectivity, controlled access to company information, practical backup procedures and a cybersecurity framework suited to a small business environment.

## Security and Risk Management

The solution applies practical security controls that protect company systems, users and data.

Key controls include:

- Department-based access control using security groups.
- Multi-factor authentication for user accounts.
- Full-disk encryption on endpoints.
- Antivirus and endpoint protection.
- Patch management for operating systems and applications.
- Daily incremental, weekly full and monthly archive backups.
- Offsite cloud backup storage.
- Security awareness training for employees.
- A structured incident response process.

The main risks considered include phishing, ransomware, hardware failure and power outages. Each risk is addressed through a combination of prevention, monitoring, backup, recovery and user training.
