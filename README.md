# 🏢 Ubuntu Innovations (Pty) Ltd — IT Support & Infrastructure Plan

## 📖 Project Overview

Ubuntu Innovations (Pty) Ltd is a fast-growing technology startup based in Cape Town, South Africa. As the organization expands into a new office environment, the company requires a scalable, secure, and high-performance IT infrastructure capable of supporting modern business operations across multiple departments.

This capstone project focuses on designing and documenting a complete foundational IT environment including:

- Business and operational requirements analysis
- Hardware infrastructure planning
- Software inventory and licensing management
- Network architecture and diagrams
- Security baseline implementation and future scalability planning

The proposed infrastructure supports a workforce of **25 employees** across Executive Management, Finance, Human Resources, Sales & Marketing, and Software Development departments.

# ⚠️ Security Baseline

Ubuntu Innovations will implement the **Principle of Least Privilege (PoLP)** across all systems and network resources. Employees will only have access to the systems, directories, and applications required for their specific job responsibilities.

Additional security measures include:

- Multi-Factor Authentication (MFA)
- Endpoint Protection & Threat Monitoring
- VPN-secured remote access
- Centralized backup storage
- Role-based access control (RBAC)
- Network segmentation for sensitive departments
