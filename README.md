## 📋 Project Overview

This repository contains all documentation and deliverables for a complete IT infrastructure and support solution designed for **Ubuntu Innovations (Pty) Ltd**, a fictional 25-person technology startup based in Cape Town, South Africa.

The project was completed as part of the Capaciti Tech Career Accelerator programme and simulates a real-world junior IT Support Specialist engagement — from initial requirements gathering through to security policy, disaster recovery planning, and career readiness materials.

## 🌐 Network Design Summary

| Device Type | Subnet |
|---|---|
| Servers / NAS | 192.168.10.0/24 |
| User Devices | 192.168.20.0/24 |
| Printers | 192.168.30.0/24 |
| Wi-Fi (Wireless) | 192.168.40.0/24 |

**Key infrastructure:** Business-grade firewall router → 24-port Gigabit managed switch → dual-band Wi-Fi 6 access points (×2), NAS (8TB RAID), laser printers (×2), UPS units (×2).

---

## 🔐 Security Highlights

- Department-based access control with dedicated security groups (`mgmt_grp`, `finance_grp`, `hr_grp`, `sales_grp`, `dev_grp`)
- Multi-factor authentication enforced for all users
- Full-disk encryption on all endpoints
- Backup schedule: daily incremental → weekly full → monthly archive → offsite cloud
- Incident response lifecycle: Detection → Reporting → Containment → Eradication → Recovery → Lessons Learned
