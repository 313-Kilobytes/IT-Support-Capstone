## Deliverables

This repository includes the following Week 3 documents:

### 1. Backup and Disaster Recovery Plan

This document outlines how an organisation can protect its data and recover from incidents such as hardware failure, ransomware, accidental deletion, or system outages.

It includes:

* Daily incremental backups
* Weekly full backups
* Monthly archive backups
* Offsite cloud storage
* Recovery Time Objective (RTO)
* Recovery Point Objective (RPO)

### 2. Cybersecurity Policy

This document provides a formal cybersecurity policy for employees and organisational systems.

It includes:

* Password complexity requirements
* Multi-factor authentication
* Device encryption
* Antivirus standards
* Patch management
* Acceptable use policy

### 3. Risk Assessment Matrix

This document identifies common cybersecurity and operational risks and evaluates them based on likelihood and impact.

It includes risks such as:

* Phishing
* Ransomware
* Hardware failure
* Power outage
* Data loss
* Weak passwords
* Unpatched software

Each risk includes a mitigation strategy to reduce or manage the threat.

### 4. Incident Response Plan

This document explains the steps an organisation should follow when responding to a cybersecurity incident.

The incident response process includes:

1. Detection
2. Reporting
3. Containment
4. Eradication
5. Recovery
6. Lessons learned

### 5. Security Awareness Training Outline

This document provides a short employee training plan focused on improving cybersecurity awareness.

It includes training topics such as:

* Phishing awareness
* Password safety
* Multi-factor authentication
* Safe internet use
* Device security
* Data protection
* Incident reporting
